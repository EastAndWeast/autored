# 一、送给测试 AI 的全局系统提示词

> **【使用方式】**：将以下框内文本直接粘贴为另一个 AI 的 System Prompt 或对话前置上下文。

```text
你现在是一名资深的软件自动化测试工程师与 QA 专家。你的任务是对本地项目「小红书 AI 运营助手 (xhs-ai-assistant)」进行全面的功能测试、边界测试与安全性验收。

【被测项目信息】
- 工作目录：<项目目录>
- 虚拟环境：./venv/bin/python
- 架构体系：FastAPI Web 服务 + SQLite 增量迁移 + 标准 Model Context Protocol (MCP) Stdio 适配器 + 异步串行防封调度器
- 核心管理命令：python run.py [start|stop|status|doctor|open|service|backup|configure]

【测试执行红线与纪律】
1. 绝对严禁向小红书或海外 Rednote 平台发送真实的发布网络请求！所有涉及发布执行的测试必须使用模拟数据或测试账号，绝不能污染用户的真实生产环境。
2. 自动化脚本测试必须使用独立的临时目录（tempfile.mkdtemp），通过 configure_data_dir() 与 rebind_db() 进行数据重绑，严禁修改或删除 data/app.db 中的真实账号和生产数据。

5. 测试结束后输出格式化的测试报告，明确指出：测试项、输入、预期结果、实际表现、判定结论（PASS / FAIL）。
```

### TC-02: 草稿落盘优先与物理隔离 (核心红线)

### TC-03: 乐观锁修订号与并发冲突控制
* **目标**：验证草稿每次修改自动递增 `revision`，带上错误的 `expected_revision` 会被拦截抛出 `REVISION_CONFLICT`。
* **输入命令**：
  ```bash
  ./venv/bin/python -c '
  import tempfile, shutil
  from pathlib import Path
  import app.config as config
  from app import models
  from app.mcp.server import handle_tool_call

  tmp = Path(tempfile.mkdtemp())
  try:
      config.configure_data_dir(tmp)
      models.rebind_db(tmp / "app.db")
      models.init_db(tmp / "app.db")
      with models.SessionLocal() as s:
          s.add(models.Account(id=1, name="测试号", status="online"))
          s.commit()

      draft = handle_tool_call("create_draft", {"account_id": 1, "title": "初稿"})
      nid = draft["note_id"]
      assert draft["revision"] == 1

      # 正常更新
      up1 = handle_tool_call("update_draft", {"note_id": nid, "title": "二稿", "expected_revision": 1})
      assert up1["revision"] == 2

      # 冲突更新: 此时当前修订号已是 2, 传入 1 必然被拦截
      conflict = handle_tool_call("update_draft", {"note_id": nid, "title": "冲突稿", "expected_revision": 1})
      assert conflict.get("isError") is True
      assert conflict["error_code"] == "REVISION_CONFLICT"
      print("TC-03 PASS: 乐观锁控制与冲突拦截验证通过")
  finally:
      models.engine.dispose()
      shutil.rmtree(tmp, ignore_errors=True)
  '
  ```
* **预期结果**：输出 `TC-03 PASS`，冲突修改返回 `error_code: REVISION_CONFLICT`。

### TC-07: 单实例守护与跨进程 Profile 锁
* **目标**：验证 PID 文件防止后台双实例启动；`fcntl` 跨进程文件锁防止两个进程同时打开同一 Chromium 账号环境。
* **输入命令**：
  ```bash
  ./venv/bin/python -c '
  import tempfile, shutil, os, fcntl
  from pathlib import Path
  import app.config as config
  from app.xhs import profile_lock

  tmp = Path(tempfile.mkdtemp())
  try:
      config.configure_data_dir(tmp)
      # 1. 模拟外部进程持有 .profile.lock
      lock_path = profile_lock._get_lock_file_path(account_id=1)
      ext_fd = os.open(str(lock_path), os.O_CREAT | os.O_RDWR, 0o600)
      fcntl.flock(ext_fd, fcntl.LOCK_EX | fcntl.LOCK_NB)

      # 2. 本进程尝试拿锁应立即被拦截 (返回 False)
      assert profile_lock.acquire(1, timeout=0.05) is False, "外部进程占用时必须互斥拦截!"

      # 3. 外部释放后，本进程拿锁成功
      fcntl.flock(ext_fd, fcntl.LOCK_UN)
      os.close(ext_fd)
      assert profile_lock.acquire(1, timeout=0.1) is True
      profile_lock.release(1)

      print("TC-07 PASS: 跨进程 Profile 互斥锁验证通过")
  finally:
      shutil.rmtree(tmp, ignore_errors=True)
  '
  ```
* **预期结果**：输出 `TC-07 PASS`。

### TC-08: 电脑休眠逾期 (Overdue) 保护机制
* **目标**：验证本地定时计划在电脑休眠/关机错过发布时间超过 60 分钟时，自动转为 `overdue` 暂停，绝不盲目批量补发。
* **输入命令**：
  ```bash
  ./venv/bin/python -c '
  import tempfile, shutil
  from pathlib import Path
  from datetime import datetime, timedelta
  import app.config as config
  from app import models
  from app.scheduler import scan_due_notes
  from app.services.publish import schedule_publish

  tmp = Path(tempfile.mkdtemp())
  try:
      config.configure_data_dir(tmp)
      models.rebind_db(tmp / "app.db")
      models.init_db(tmp / "app.db")
      with models.SessionLocal() as s:
          s.add(models.Account(id=1, name="测试号", status="online"))
          s.commit()

      img = config.UPLOADS_DIR / "sample.png"
      img.write_bytes(b"\x89PNG\r\n\x1a\n" + b"\x00" * 32)

      now = datetime.now()
      with models.SessionLocal() as s:
          n = models.Note(account_id=1, title="休眠遗留笔记", media_paths=["sample.png"], status="draft")
          s.add(n)
          s.commit()
          nid = n.id

      # 安排发布到 10 分钟后
      job = schedule_publish(note_id=nid, mode="schedule", scheduled_at=now + timedelta(minutes=10))

      # 模拟电脑关机: 时间流逝 2 小时 (超过 60 分钟阈值)
      with models.SessionLocal() as s:
          j = s.get(models.PublishJob, job.id)
          j.effective_at = now - timedelta(hours=2)
          j.scheduled_at = now - timedelta(hours=2)
          s.commit()

      # 执行唤醒扫描
      scan_due_notes()

      with models.SessionLocal() as s:
          j_after = s.get(models.PublishJob, job.id)
          n_after = s.get(models.Note, nid)
          assert j_after.status == "overdue", "必须转为 overdue 暂停，绝不能是 queued!"
          assert n_after.status == "overdue"
          assert j_after.last_error_code == "OVERDUE_SKIPPED"

      print("TC-08 PASS: 电脑休眠开机逾期保护验证通过，防盲目批量补发")
  finally:
      models.engine.dispose()
      shutil.rmtree(tmp, ignore_errors=True)
  '
  ```
* **预期结果**：输出 `TC-08 PASS`。

### TC-10: 区分「未采集」与「真实读数为0」
* **目标**：验证 `get_notes_stats_service()` 明确区分未采集（`pending_first_fetch`）与已采集真实读数为 0（`verified_zero`）。
* **输入命令**：
  ```bash
  ./venv/bin/python -c '
  import tempfile, shutil
  from pathlib import Path
  from datetime import datetime
  import app.config as config
  from app import models
  from app.services.stats import get_notes_stats_service

  tmp = Path(tempfile.mkdtemp())
  try:
      config.configure_data_dir(tmp)
      models.rebind_db(tmp / "app.db")
      models.init_db(tmp / "app.db")

      with models.SessionLocal() as s:
          s.add(models.Account(id=1, name="测试号", status="online"))
          # 笔记 A: 未采集
          na = models.Note(id=1, account_id=1, title="未采集笔记", status="published", published_at=datetime.now())
          # 笔记 B: 已采集但读数为 0
          nb = models.Note(id=2, account_id=1, title="真实0笔记", status="published", published_at=datetime.now())
          sb = models.NoteStat(note_id=2, impression=0, read=0, like=0, fetched_at=datetime.now())
          s.add_all([na, nb, sb])
          s.commit()

      stats = get_notes_stats_service(account_id=1)
      s_map = {item["note_id"]: item for item in stats}
  ```
