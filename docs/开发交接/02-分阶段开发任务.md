## P1 草稿与可靠任务 (已完成 ✅)

依赖 P0。

- [x] 增加仅保存草稿的服务和接口（`create_draft`, `update_draft`, `POST /api/v1/drafts`, `PATCH /api/v1/drafts/{id}`）；允许无媒体草稿，发布时才做完整校验。
- [x] 将时间修改和发布意图分离；修改正文、清空时间均不能隐式触发立即发布。
- [x] 笔记绑定账号 ID；归属字段显式展示，保留账号/状态组合筛选。
- [x] 新增持久 PublishJob、幂等键（`idempotency_key`）、内容修订号（`revision`）和发布尝试记录（`PublishAttempt`）。
- [x] 明确状态迁移，通过快照固化（`content_snapshot`）防止同一笔记/修订重复排期或错配提交。
- [x] 崩溃后 publishing/提交中任务进入待核对（`verifying`），先查平台再重试，绝不盲目自动重发。
- [x] 平台定时到点进入核对流程（置 `unverified`/待核对），不能仅依时间设为已发布。
- [x] 发布成功页、平台笔记 ID、实际详情链接分别保存（`xhs_publish_url` 与 `xhs_url` 解耦）；历史成功页链接不能继续作为“查看笔记”。
- [x] 对旧记录保留历史事实：有平台证据再确认，没有证据标记待核对，不批量自动重发。
- [x] 区分平台加载超时、账号失效和采集无数据，不让网络超时覆盖有效账号状态。

出口达成：保存草稿永不入队；重复调用只产生一个任务；提交中崩溃不会自动重发；已发布只能由平台记录证据确认。自动化验证套件 `tests/test_p0_p1.py` 15 项测试全部通过，全量回归测试 31 项全绿通过。

## P2 AI 接入 (已完成)

依赖 P1。

- 提取应用服务层，新增 MCP 适配器；返回结构化结果和清晰的下一步（next_action）。
- 实现账号查询、登录任务、草稿 CRUD、素材导入、排期、取消、任务查询、统计查询（共 14 个核心工具）。
- 工具调用发布只能排入后台，不在 MCP 请求里等待上传、浏览器和采集完成。
- Skill 教会 AI 先识别账号、询问缺失关键事实、生成并保存、展示预览，再按用户明确要求排期。
- 如果用户已明确指定账号、内容和发布时间，沿用授权完成安排，不无故重复确认。
- 账号同名/不明确时不猜测；使用 account_id。素材导入后由服务托管，不能依赖聊天临时文件一直存在。
- 先用 Codex 完成真实端到端接入，再适配 WorkBuddy 包装和安装配置。
- 图像生成不可用时说明并保存草稿，不伪造已生成媒体。

出口达成：

- 自动化验证套件 `tests/test_mcp.py` 13 项测试全部通过（包含 JSON-RPC 协议层、工具调用、并发乐观锁控制、素材导入校验、防重排期发布及端到端 AI 完整业务链路）。全量测试套件 44 项全部通过。
